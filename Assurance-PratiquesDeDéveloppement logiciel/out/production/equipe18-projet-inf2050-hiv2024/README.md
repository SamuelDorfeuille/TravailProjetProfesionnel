#  README
Voici les technologies utilisé pour notre projet:


1. Le langage de programmation utilisé est JAVA.
2. L'IDE de développement est IntelliJ.
3.Le format JSON est utilisé pour le dossier d'entrée et de sortie du projet.


La compilation et l'exécution sont effectuées en appuyant sur le bouton vert (symbole de lecture) dans IntelliJ.
