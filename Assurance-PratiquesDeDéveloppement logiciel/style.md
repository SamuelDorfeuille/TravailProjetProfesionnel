
# Style
Voici le style utilisé pour notre projet


1. La langue utilisée pour l’élaboration du projet est le français.
2. L’application est développée selon plusieurs méthodes et contient une fonction equipe18.
3. Le code (variable) contient quelques abréviations, mais celles-ci sont simples et intuitives.
4. Nous respectons les 10 lignes comme mentionné dans l'énoncé du TP.
5. Nous faisons de notre mieux pour limiter chaque ligne à 80 caractères.
